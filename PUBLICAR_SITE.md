# Publicação pública e independente — GitHub Pages

O site já está preparado para hospedagem estática e possui quatro idiomas: Português, English, Français e Español.

## Publicar na internet
1. Entre em https://github.com e crie uma conta, caso necessário.
2. Crie um repositório público com nome `plant-nutrition-group` (ou outro nome).
3. Envie **todo o conteúdo desta pasta**, incluindo `index.html`, `logo-grupo.png`, `publications.json`, `projects.json` e a pasta `.github`.
4. No repositório, abra Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. O endereço será `https://SEU_USUARIO.github.io/plant-nutrition-group/`. Não substitua SEU_USUARIO até conhecer seu usuário real.
6. Para usar um domínio próprio, compre um domínio e configure-o em Settings > Pages > Custom domain, incluindo os registros DNS solicitados pelo GitHub.

**O site ainda não está publicado.** A publicação requer uma conta e uma ação autorizada do proprietário.

Os dados do Lattes já importados estão nos arquivos JSON; atualizações futuras do currículo exigem um novo XML ou acesso autorizado ao serviço Lattes Extrator. A equipe ainda depende de fonte oficial.
